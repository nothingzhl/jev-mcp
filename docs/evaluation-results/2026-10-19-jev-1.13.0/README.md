## 两项排序响应错误

migration-lock-order 与 chinese-task 各有两个 Score，与所返回概率的加权值相差 0.02，超过应用现有 0.01 容差；概率和均为 1，legend 匹配。这与此前已修复的二进制浮点边界误报不同，不能再用数值 epsilon 处理。

例如一个分数为 0.69，但返回概率 `{0:0.42, 1:0.50, 2:0.07, 3:0.01, 4:0}` 的加权值为 0.67；另一个分数 3.94 对应所返回概率的加权值 3.96。四个数值证据保存在 [response-issues.json](response-issues.json)。

已查阅当前官方 [Score 文档](https://docs.typesafe.ai/primitives/score) 与 [HTTP API 文档](https://docs.typesafe.ai/api)，其契约将 score 描述为概率加权值，但未明确返回精度及舍入误差界限。分别舍入可能解释差异，目前没有足够契约证据据此放宽校验。保持 INVALID_RESPONSE，并将它们排除在质量分母外、保留在错误率分母中；需要确认上游精度契约后再设计兼容修复及回归测试。
