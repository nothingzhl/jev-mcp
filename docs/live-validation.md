## 已完成的修复

1. 云环境 Node 24.19 的进程需设置 NODE_USE_ENV_PROXY=1，保留平台 HTTP_PROXY/HTTPS_PROXY 和 CA 信任，不绕过代理或禁用 TLS。已将变量建议和启动说明保存到环境草稿，尚需在环境设置保存并发布；当前验证命令通过进程级变量启用。最低支持的 Node 22.16 不因此获得该 Node 开关的兼容性承诺。
2. 诊断响应中一个 Score 的 `score - expectation` 为 `-0.010000000000000231`。现有代码原本容许闭区间 0.01 的舍入差，但二进制浮点误差使边界失败。校验添加 1e-12 数值余量，保留原有语义，不改写响应的分数、概率或规则阈值。
3. 合成回归测试覆盖 3.91/3.93 相对于期望 3.92 的两个边界均可通过，3.9099/3.9301 仍被拒绝。原有坏分布、越界及矛盾分数的检查继续执行。

3 次调用尝试用完后只运行离线测试，没有追加真实请求。修复后的真实复测仍待后续执行。初始计划的 39 次总尝试预算已使用 3 次，后续执行必须扣除调试请求，不能再直接追加 39 次。
