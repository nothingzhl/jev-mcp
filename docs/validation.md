# 骨架交付验证

日期：2026-10-19。实际本地环境：macOS、Node.js v26.3.0。项目推荐使用 Node24，CI 配置覆盖22.16与24；本轮未执行远端 CI，也未验证这两个 Node 版本的实际运行。

## 验证范围

- `npm ci --offline`：基于锁文件与本地 npm 缓存完成干净重装；重装后重新运行 check 与 demo 通过。
- `npm run check`：strict 类型检查、52项离线测试、构建均通过。
- `npm run demo`：正常输出候选排序请求计划，没有调用模型或写入数据库。
- 入口测试启动真实 stdio 子进程并经官方 MCP Client 列工具、执行 dry run、检查缺 key 和无效输入。
- 通过符号链接启动 CLI/MCP 的回归路径已覆盖。
- Provider 测试执行官方 SDK，注入合成 HTTP fetch，覆盖原生请求字段、真实返回模型的记录、空用量、鉴权/连接失败、总时限、SDK 重试和坏响应。
- 规则测试覆盖同 state 批量问题、排序不丢候选、稳定并列、阈值、空证据、unknown 与输入界限。
- SQLite 测试覆盖重开持久化、私有权限、参数绑定、字段白名单、安全错误、版本拒绝和关闭。
- 服务测试覆盖并发上限、仅元数据持久化、错误不泄漏原文、存储失败不重复调用模型。

所有推理结果均来自合成测试响应，未发起真实 Jev API 调用，未产生模型质量、生产准确率、阈值校准或效率收益证据。测试通过不等于实际推理效果通过。
